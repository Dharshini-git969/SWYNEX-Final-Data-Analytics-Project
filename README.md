# SWYNEX Final Data Analytics Project

## 📊 Project Overview

This project is the final submission for my Data Analytics Internship at SWYNEX Technologies.

The project demonstrates the complete data analytics workflow, from data cleaning and exploratory analysis to interactive dashboard development and business insights.

## 🎯 Problem Statement

The objective of this project is to analyze online retail transaction data to understand sales performance, customer purchasing patterns, product performance, cancellations/returns, and sales trends over time.

The analysis helps transform raw transactional data into meaningful insights that can support better business and sales decisions.

## 📁 Dataset

The project uses an Online Retail transaction dataset containing information about:

- Invoice Number
- Stock Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

The dataset was prepared and cleaned before performing the analysis.

## 🧹 Task 1 – Data Cleaning & Preparation

The raw dataset was cleaned and prepared for further analysis.

Key steps included:

- Removing duplicate records
- Identifying cancelled/returned transactions
- Handling missing Customer IDs
- Checking data types
- Identifying zero-price transactions
- Creating additional fields required for analysis
- Performing data-quality checks

## 🔎 Task 2 – Exploratory Data Analysis

Exploratory Data Analysis was performed to identify patterns and trends in the retail transactions.

The analysis included:

- Sales analysis
- Quantity analysis
- Unit price analysis
- Customer analysis
- Country-wise analysis
- Time-based sales trends
- Outlier identification
- Transaction and cancellation analysis

## 📈 Task 3 – Interactive Power BI Dashboard

An interactive Power BI dashboard was developed to present the key findings visually.

The dashboard allows users to explore the data using interactive visuals and filters.

### Dashboard Features

- KPI metrics
- Sales performance analysis
- Product/transaction analysis
- Customer analysis
- Time-based trends
- Interactive filters
- Data visualizations

## 💡 Key Insights

The analysis helped identify important patterns in:

- Overall sales performance
- Customer purchasing behaviour
- Product-level performance
- Monthly sales trends
- Quantity and price distributions
- Cancellation/return patterns
- Geographic sales distribution
